# trie-course
Цель курсового проекта – проектирование, программная реализация префиксного дерева (Trie) на языке C++ и экспериментальное исследование поиска по словарю с его помощью, а также сравнительный анализ эффективности с альтернативными структурами данных.
Актуальность темы:
В современной компьютерной лингвистике, системах обработки текстовой информации и базах данных одной из наиболее критичных к вычислительным ресурсам операций является поиск информации по текстовым ключам. С ростом объемов обрабатываемых данных – в частности, при создании систем автодополнения, проверки орфографии, интеллектуального поиска по словарям – традиционные структуры данных, такие как сбалансированные двоичные деревья поиска или хеш-таблицы, могут сталкиваться с рядом ограничений. Хеш-таблицы, обеспечивая среднее время поиска O(1), требуют вычисления хеш-функции для всей строки и не поддерживают эффективный поиск по префиксу или упорядоченный обход ключей.
В качестве эффективной альтернативы выступает префиксное дерево, в котором время поиска, вставки и удаления ключа зависит исключительно от длины самого ключа L, а не от общего количества элементов в структуре N. Это делает Trie незаменимым инструментом при решении задач префиксного поиска и автодополнения в больших словарях. Однако платой за высокую скорость операций является повышенное потребление оперативной памяти. В связи с этим исследование различных вариантов реализации префиксного дерева на языке программирования высокого уровня C++ (например, с использованием массивов, динамических списков или хеш-таблиц на узлах) и экспериментальная оценка их эффективности являются актуальной инженерной и научной задачей.
Объект исследования – структуры данных для эффективного хранения и поиска текстовой информации.
Предмет исследования – алгоритмические особенности, программная реализация на языке C++ и характеристики эффективности префиксного дерева при решении задачи поиска по словарю.
Для достижения поставленной цели необходимо решить следующие задачи:
1.	Изучить теоретические аспекты структуры данных «префиксное дерево», принципы выполнения основных операций (поиск, вставка, удаление) и область её применения.
2.	Разработать техническое задание и спроектировать архитектуру программного модуля, включая иерархию классов и структуру узлов префиксного дерева для реализации поиска по словарю.
3.	Программно реализовать префиксное дерево на языке C++.
4.	Провести экспериментальное исследование разработанной структуры данных на различных объемах входных данных (словарях) для оценки временных затрат и расхода памяти.
5.	Выполнить сравнительный анализ эффективности Trie с альтернативными контейнерами (например, std::set или std::unordered_set) и сформулировать обоснованные выводы.
